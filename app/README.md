# OUT Tennis Club — приложение

Полный исходный код закрытого приложения: React/Vite, сервер Node.js, авторизация, рейтинг, карточки игроков, турниры, фотоальбомы и установка на домашний экран телефона.

Работающий сервис: https://outclub.inishev.ru

## Запуск

Нужен Node.js 22 или новее.

```sh
cd app
npm ci
npm run build
npm run setup
npm start
```

Сервер слушает http://127.0.0.1:4173. Для разработки используйте `npm run dev` вместо `npm start`. Настройка пароля проходит интерактивно; повторный setup меняет пароль и отзывает предыдущие сессии.

## Закрытые данные

Для наполненного приложения нужны `private/data/club.json` и `private/media/`. Они передаются владельцу отдельно по защищённому каналу и не публикуются в этом открытом репозитории. Анкеты, фотографии, выгрузки Telegram, ключи и настройки `.runtime/` в Git не входят. Существующая рабочая версия на сервере продолжает использовать свои данные.

Скрипты `scripts/import-data.py`, `enrich-presentation.py`, `optimize-images.py` воспроизводят импорт и подготовку локального снимка. Для Python нужны openpyxl и Pillow; portraits.swift использует Apple Vision на macOS. Автоматическая синхронизация не реализована.

## Проверки

```sh
npm run build
npm run test:code
```

`npm test` дополнительно проверяет закрытый клубный снимок, если добавлены `private/data/club.json` и соответствующие медиа; без них проверки данных пропускаются.

## Публикация

Приложению нужен Node-сервер за HTTPS-прокси. GitHub Pages обслуживает только исходную страницу в корне репозитория; папка app — исходники приложения, а не отдельная работающая версия. Шаблоны настройки сервера находятся в deploy/. Для обновления рабочего сервиса сохраняйте его private/ и .runtime/; не запускайте setup повторно без намерения сменить пароль.

Все организационные действия клуба остаются в Telegram. Сайт показывает данные и не принимает записи на турниры или результаты матчей.

Импортёр читает проверочные значения из закрытого `private/data/snapshot-settings.json`: исходные имена, суммы, матчи и привязки медиа. Этот файл подготовлен отдельно и не публикуется. Рабочая логика импортёра сохранена; реальные значения больше не зашиты в публичный код.

## Размещение в Yandex Cloud

В каталоге [serverless](serverless/README.md) находится адаптер Cloud Functions + закрытый Object Storage. Он сохраняет вход по паролю, защиту данных, отзыв сессий и ограничение попыток входа. Gateway вызывает функцию от сервисного аккаунта; бакет не открывается публично. VPS для этой версии не нужен. Настройки среды, карта файлов, данные и секреты передаются отдельно.
