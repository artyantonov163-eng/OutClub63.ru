# OUT Club private HTTP server

Requires Node 20+. No runtime dependencies. Entry point: `node server/index.mjs`.

The server requires a configured shared password before it binds. Run `node server/setup.mjs` to enter one without echo (minimum 12 characters), or provide it on standard input. Empty input generates a password. Never pass a password in an argument. The password is saved in `.runtime/access.txt` (0600), and only its scrypt hash plus session signing material are kept in `.runtime/auth.json` (0600). `.runtime/` must stay excluded from Git, artifacts, and public hosting. Setup rotates all signing material and invalidates existing sessions; the running server reloads configuration on every request.

Local defaults: `HOST=127.0.0.1`, `PORT=4173`, HTTP cookie. For deployment behind an HTTPS reverse proxy, set `PUBLIC_ORIGIN=https://your-domain.example` and `COOKIE_SECURE=true`. Bind privately behind the proxy. By default rate limits use the direct peer address. Optional `TRUST_PROXY=true` requires an explicit `PUBLIC_ORIGIN` and trusts a single valid `X-Forwarded-For` IP only when the direct peer is loopback (127.0.0.1, ::1, or mapped 127.0.0.1). The trusted proxy must overwrite this header with the actual remote client address, never append to or preserve an incoming header. Invalid, multi-value, and non-loopback forwarding headers are ignored. Never expose `private/` or `.runtime/` through the proxy's static file routes.

Public content is limited to `dist/client/`; source data is read at runtime from `private/data/club.json`. Authenticated media resolves only under `private/media/`. Realpath checks prevent symlink escapes. Private responses never cache. POST login/logout require an exact Origin match. Session cookies are signed, HttpOnly, SameSite Strict, and expire after 30 days. Logout clears the cookie and persists its random session ID and expiry in `.runtime/revocations.json` (0600), so replay remains blocked after restart. Writes are serialized and atomic; expired IDs are pruned on startup and logout. No complete cookies, passwords, or player data are stored there. Corrupt state causes startup to fail closed. Run one Node server instance against this local state; multiple instances require a shared transactional store. Global password rotation permanently invalidates all prior tokens. A shared password cannot revoke only one member's access.

`createServer({root, configPath, config, origin, secureCookie, sessionTtlMs, now, rateLimit, rateWindowMs, trustProxy})` returns an unbound Node HTTP server. `config` and `now` are primarily test fixtures. Default login budget is 10 requests per 15 minutes per peer, including successful attempts.

Verify: `node --test tests/auth.test.mjs`. These tests bind only loopback and need local socket permission in restricted environments.
